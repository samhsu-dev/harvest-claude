# Harvest Claude

> Terminal application (Rust, ratatui) that renders running Claude Code sessions as animated pixel-art farm characters using half-block Unicode rendering.

Detects Claude Code sessions by watching `~/.claude/projects/` for active JSONL transcripts. View-only, with terminal-window focus as the only control action. Renders a 28x16 tile farm (8x8 pixel tiles) with characters, companions, produce piles, and an agent panel showing one summary line per agent.

## Instructions for Agents

- Read `docs/design.md` for type specifications and architecture.
- Read `docs/impl.md` for Rust crate APIs and gotchas before writing integration code.
- Write pixels directly into the ratatui `Buffer` (no Canvas widget). One cell holds two vertical pixels: `▀` with fg for the top pixel and bg for the bottom pixel.
- Drive the loop from a 16 ms tick on a plain thread. No tokio.
- Watch files with `notify` and `std::sync::mpsc`. Poll readers every `JSONL_POLL_MS`, not every tick.
- Parse JSONL line by line with `serde_json::from_str::<Value>`. Buffer partial lines as bytes.
- Embed all sprites as compile-time data. No runtime asset loading.
- Run `cargo clippy --all-targets --all-features -- -D warnings` and `cargo test --workspace --all-features` before completing any change.

## Configuration

| Flag | Effect |
|------|--------|
| `--layout <path>` | Load this layout. A missing path is an error. |
| `--watch-dir <dir>` | Scan `<dir>` in addition to `~/.claude/projects`. A missing path is an error. |

- Log files: `~/.harvest-claude/logs`, daily rotation, at most 3 files.
- Minimum terminal: `MIN_TERMINAL_COLS=40`, `MIN_TERMINAL_ROWS=8`. Below it the screen shows a plain notice.
- Farm size in cells: `cols*8` columns, `rows*8/2` rows. Default grid 28x16 needs 224x64.
- Panel text widths: `NAME_MAX_WIDTH=12`, `LABEL_MAX_WIDTH=8`.

## Gotchas

- Build `App` before `TerminalGuard`. A startup error then prints on a normal screen.
- `restore_terminal` is idempotent. The panic hook and `Drop` both call it.
- Truncate by display width with `unicode-width`, never by `char` count. CJK characters take 2 columns.
- The panel lists one row per non-Dormant agent plus a produce footer. Dormant agents are skipped by arrows and clicks.
- Focus runs on a spawned thread. The UI never waits for `lsof` or `osascript`.
- `Action` keeps every variant listed in `docs/design.md`.

let mut state = OfficeState::from_layout(layout);

## API

| Item | Meaning |
|------|---------|

| `start_delivery`, `take_delivery` | Carry produce to the barn or warehouse |

| `Character::anim_for_tool` | Tool name to `AnimType` |

## Configuration

| Constant | Value |
|----------|-------|
| `WALK_FRAME_MS` | 150 |
| `TYPE_FRAME_MS` | 300 |
| `WALK_SPEED` | 3.0 tiles per second |
| `REST_DURATION` | 120 to 240 s |
| `MAX_AGENTS` | 8 |

- Warehouse file: `~/.harvest-claude/warehouse.json`.

## Gotchas

- Seats derive from furniture: `STUMP_*` and `FISHING_SPOT` are seats. The stump variant sets the facing direction.
- `Character::update` counts completed wander paths in a saturating counter. Never use unchecked `u8` addition.
- Bubbles: `BubbleKind::Permission` stays until the tool result arrives. `BubbleKind::Waiting` marks turn end.
- A tool result in Permission state returns the character to Active and clears the bubble.
- A background launch adds a companion. The final result for that tool id removes it.
- `load_warehouse` returns `Result`. A corrupt file is renamed `warehouse.json.corrupt` with a warning.
- `save_warehouse` writes a temp file and renames it. A crash leaves no partial file.
- No matrix spawn or despawn effect exists.

# Agent Detection

> Directory scanning, transcript tailing, per-agent state, timers, and window focus.

## Quick Start

```rust
let mut scanner = DirectoryScanner::new(dirs)?;   // Vec<PathBuf>
for path in scanner.initial_scan() {
    let id = registry.add_agent(/* session, path, project */)?;
    registry.replay(id)?;                          // apply transcript tail
}
for (id, applied) in registry.poll_all() { /* update characters */ }
```

## Key Files

| File | Responsibility |
|------|---------------|
| `src/watcher/scanner.rs` | `DirectoryScanner`, `session_info(path)`, `notify` events |
| `src/watcher/registry.rs` | `AgentRegistry`: agents, readers, palette claims |
| `src/watcher/agent.rs` | `Agent`: state, summary, identity |
| `src/watcher/jsonl.rs` | `JsonlReader` tailing |
| `src/watcher/parser.rs` | Record parsing and event extraction |
| `src/watcher/timer.rs` | `TimerManager`, `PollInterval` |
| `src/watcher/focus.rs` | `focus_agent_window(cwd: String)` |

## API

| Type | Methods |
|------|---------|
| `DirectoryScanner` | `new(Vec<PathBuf>)`, `initial_scan`, `poll`, `forget` |
| `AgentRegistry` | `new`, `add_agent`, `replay`, `remove_agent`, `poll_all`, `get`, `get_mut`, `agents`, `has_path` |
| `Agent` | `new`, `apply -> ApplyOutcome`, `summary`, `display_name`, `is_running_non_exempt` |
| `TimerManager` | `start_permission`, `cancel_permission`, `start_text_idle`, `cancel_text_idle`, `cancel_all`, `check_expired` |
| `PollInterval` | `new`, `due` |

## Configuration

| Constant | Value |
|----------|-------|
| `PERMISSION_TIMER_MS` | 7000 |
| text-idle timer | 5000 ms |
| `JSONL_POLL_MS` | 500 |
| `REPLAY_TAIL_BYTES` | 65536 |
| Dormant after silence | 600 s |
| Removed after silence | 7200 s |
| `MAX_AGENTS` | 8 |

## Gotchas

- Discovery root is `~/.claude/projects`. `--watch-dir` adds directories.
- `session_info` accepts `<hash>/<uuid>.jsonl`, with or without a `sessions` directory. Paths under `subagents/` are rejected.
- The scanner drains `notify` events every tick. Readers poll on `PollInterval`.
- A refused adoption at the agent limit calls `forget`. The next write retries it.
- A write to a Dormant agent wakes it, regardless of the limit.
- Replay applies the transcript tail. An adopted agent that runs a tool shows Active and its summary, with a permission timer but no bubble.
- The agent display name is `<dir> (<branch>)` from the `Identity` event.
- Summary precedence: running tool `<name>: <detail>`, assistant text, title, last prompt.
- Window focus uses `Identity.cwd`: `lsof -d cwd -Fpn` finds the pid, then escaped AppleScript raises the Terminal or iTerm tab.
- No dismiss tracking and no `/clear` tracking exist.

let sprite = character_sprite(palette, Direction::Down, AnimType::Walk, frame);

## API

| Item | Meaning |
|------|---------|
| `SpriteData` | `Vec<Vec<Pixel>>`; transparent pixel is `T` |
| Character sprite | 8x8 pixels per `(direction, anim, frame)` |
| `companion_sprite(kind, frame)` | 8x8, two frames: normal and bob |
| `BubbleKind` | `Permission`, `Waiting` |
| `Direction` | `Down`, `Up`, `Left`, `Right` |

## Configuration

| Constant | Value |
|----------|-------|
| `TILE_SIZE` | 8 pixels |
| Palette count | 6: Farmer, Rancher, Gardener, Berry picker, Harvest worker, Fisher |
| `WALK_FRAME_MS` | 150 |
| `TYPE_FRAME_MS` | 300 |

## Gotchas

- Palette index wraps at 6 (`palette % 6`). The registry assigns the least-used palette.
- Once all 6 palettes are in use, a random hue shift is added to the next agent.
- `Left` mirrors the `Right` sprite. Only `Down`, `Up`, and `Right` are drawn.
- Each character sprite is 8 pixels wide and 8 tall. Each terminal cell shows two vertical pixels.
- Sprites are compile-time data. No asset files load at runtime.
- Produce piles grow by tier: `Warehouse::tier(produce)` selects the sprite variant.

# Layout Format

> `OfficeLayout` schema, furniture catalog, default farm, and load policy.

## Quick Start

```json
{
  "version": 1,
  "cols": 28,
  "rows": 16,
  "layout_revision": 14,
  "tiles": [1, 1, 2, 5, 0],
  "furniture": [{"uid": "f1", "type": "CROP_PLOT", "col": 3, "row": 4}]
}
```

## Key Files

| File | Responsibility |
|------|---------------|
| `src/layout/persistence.rs` | `load_or_default`, `validate_layout`, default layout |
| `src/layout/furniture.rs` | Catalog, footprints, seats, categories |
| `src/types.rs` | `TileType`, `OfficeLayout`, `PlacedFurniture` |

## Schema

| Field | Type |
|-------|------|
| `version` | `u32` |
| `cols`, `rows` | Grid size. Default 28x16, maximum 64x64 |
| `tiles` | `Vec<u8>`, `cols*rows` entries, row-major |
| `furniture` | `Vec<PlacedFurniture>` |
| `tile_colors` | Optional per-tile colors |
| `layout_revision` | Optional `u32` |

`PlacedFurniture`: `uid`, `type`, `col: i16`, `row: i16`, optional `color`.

`TileType`: Void 0, Grass 1, GrassDark 2, Dirt 3, DirtDark 4, Water 5, Sand 6, Stone 7, Fence 100.

## Furniture Catalog

All entries have a 1x1 footprint.

| Group | Types |
|-------|-------|
| Crops | `CROP_PLOT`, `CROP_PLOT_ON` |
| Seats | `STUMP_FRONT`, `STUMP_BACK`, `STUMP_LEFT`, `STUMP_RIGHT`, `FISHING_SPOT` |
| Trees | `TREE`, `TREE_FRUIT` |
| Structures | `CABIN_WALL`, `BARN_WALL`, `HOME`, `BARN`, `CHICKEN_COOP`, `COW_PEN`, `WELL`, `MAILBOX`, `MAILBOX_ON`, `SCARECROW` |
| Decor | `LANTERN`, `FLOWER`, `BUSH` |
| Produce piles | `WHEAT_PILE`, `FRUIT_BASKET`, `FISH_PILE` |
| Fences | `FENCE_H`, `FENCE_V` |

## Configuration

- User layout path: `~/.harvest-claude/layout.json`. `--layout <path>` overrides it.
- `BUNDLED_REVISION` = 14.

## Load Policy

| State of the file | Result |
|-------------------|--------|
| Missing | Default layout written and used |
| `layout_revision` below `BUNDLED_REVISION` | Copied to `layout.json.bak-r<rev>`, then replaced by the default |
| Invalid (parse error, size mismatch, out-of-range furniture) | Default used in memory, file untouched |
| Missing explicit `--layout` path | Error |

## Gotchas

- `validate_layout` rejects furniture outside the grid and `tiles` of the wrong length.
- Seats derive from `STUMP_*` and `FISHING_SPOT`. A layout without seats leaves agents idle.
- Furniture categories: `desk` for crops, `seating` for seats, `electronics` for mailboxes, `building` for `HOME` and `BARN`, `decor` for the rest.
- Add a new furniture type in the catalog and in the sprite table together.

# JSONL Protocol

> Claude Code transcript record types, event extraction, and reader limits.

## Quick Start

```rust
let mut reader = JsonlReader::new_from_tail(path, REPLAY_TAIL_BYTES)?;
for line in reader.read_new_lines()? {
    for event in extract_events(&line) {   // stateless
        agent.apply(event);
    }
}
```

## Key Files

| File | Responsibility |
|------|---------------|
| `src/watcher/jsonl.rs` | `JsonlReader`: byte-level tailing |
| `src/watcher/parser.rs` | `parse_line`, `extract_events`, `tool_detail`, `is_turn_end`, `is_non_exempt_tool`, `truncate_chars` |

## API

| Item | Meaning |
|------|---------|
| `JsonlReader::new_from_tail(path, tail)` | Start `tail` bytes before the end; discard the cut first line |
| `JsonlReader::new_from_start(path)` | Start at byte 0 |
| `read_new_lines()` | Complete lines since the last call, at most `JSONL_READ_CAP` bytes per call |
| `offset()` | Current byte offset |

`AgentEvent`: `ToolStart`, `ToolDone` (with `background_launch` flag), `TurnEnd`, `Text`, `Title`, `Prompt`, `Identity`.

## Records

Location: `~/.claude/projects/<hash>/<session-id>.jsonl`. Append-only, one JSON object per line.

| `type` | Content | Event |
|--------|---------|-------|
| `assistant` | `tool_use` blocks (`id`, `name`, `input`) | `ToolStart` |
| `assistant` | `text` blocks | `Text` |
| `user` | `tool_result` blocks (`tool_use_id`) | `ToolDone` |
| `user` | string or array prompt content | `Prompt` |
| `system` | top-level `subtype: "turn_duration"` | `TurnEnd` |
| `ai-title`, `custom-title` | session title | `Title` |
| `last-prompt` | last user prompt | `Prompt` |
| any record with `cwd` and `gitBranch` | project identity | `Identity` |

- `thinking` blocks are ignored.
- A `tool_result` reading "Async agent launched successfully." sets `background_launch`. The final result of that tool id ends the companion.

## Tool Animation

| Animation | Tools |
|-----------|-------|
| Farm | `Write`, `Edit`, `MultiEdit`, `NotebookEdit`, unknown tools |
| Harvest | `Read`, `Grep`, `Glob`, `WebFetch`, `WebSearch`, `Bash`, `Execute`, `Terminal` |

Exempt tools never start the permission timer: `Task`, `Agent`, `AskUserQuestion`.

## Configuration

| Constant | Value |
|----------|-------|
| `JSONL_READ_CAP` | 65536 bytes per read |
| `JSONL_MAX_LINE_BYTES` | 8 MiB |
| `REPLAY_TAIL_BYTES` | 65536 |
| `JSONL_POLL_MS` | 500 |

## Gotchas

- Buffer raw bytes and decode only complete lines. A multibyte character split across reads stays intact.
- A line above `JSONL_MAX_LINE_BYTES` is skipped without growing the buffer.
- A file shorter than the stored offset resets the reader to byte 0.
- Turn end is the top-level `subtype: "turn_duration"`. Text-only turns lack it, so the 5 s text-idle timer is the fallback.
- User `content` is a string or an array. Check the type before access.
- `extract_events` keeps no state. Per-tool tracking lives in `Agent::apply`.
